# 多视频对比复盘 Skill 使用指南

> 给你一堆视频，它帮你对比出好的和差的到底差在哪，然后总结出一套你可以照着做的内容模板。

---

## 这个工具能帮你做什么？

你有没有过这种情况：

- 我拍了一堆视频，有的爆了有的扑了，但不知道为什么？
- 想总结一下"什么样的视频容易火"，但凭感觉总结不出来？
- 有了一堆数据，但不知道怎么从数据里提炼出可复制的方法？

这个工具就是帮你干这个的。

**你只需要做一件事：给它一堆视频（链接/文件都行）+ 对应的数据表格。**

然后它会自动帮你：
1. 把好的视频和差的视频分成两组
2. 对每条视频做详细拆解
3. 好组 vs 差组逐维度对比，找出关键差异
4. 总结出几条爆款规律
5. 给你一套可以直接套用的内容模板 + 发布前检查清单

---

## 怎么用？（三步搞定）

### 第一步：把 Skill 安装到豆包里

把 `doubao-video-comparison` 这个文件夹，放到你的豆包 skills 目录里就行。

---

### 第二步：准备好你的视频和数据

你可以用两种方式给它：

**方式一：表格 + 链接（推荐）**

做一个简单的表格，包含这些列：
| 视频标题 | 播放量 | 5秒完播率 | 引流次数 | 视频链接 |
|---|---|---|---|---|

然后把表格发给它，再告诉它："帮我对比一下这些视频，找出好差差异。"

**方式二：视频文件 + 数据**

直接把视频文件拖进对话框，再把数据告诉它就行。

---

### 第三步：等它出报告，然后打开看

大概等 10-20 分钟（视频越多等越久），它会给你一个 HTML 文件。

你用浏览器打开这个文件，就能看到完整的对比复盘报告了。

---

## 报告里有什么？

### 📊 数据总览
所有视频的关键指标一览表，好的和差的用颜色区分。

### 🔍 关键差异点（Top 5）
最重要的5个好差差异，每个差异都告诉你：
- 好的视频是怎么做的，差的是怎么做的
- 为什么这个差异会影响数据
- 正反案例对照

### 💡 爆款规律总结
从差异里提炼出的3-5条规律，比如：
- "先让用户觉得买贵了，再讲优惠"
- "具体数字比形容词更有力量"
- "品牌要融入剧情，不要只在片尾出现"

### 📝 可复制内容模板
直接给你一个黄金结构模板：
```
0-2秒：做什么
2-4秒：做什么
4-9秒：做什么
9-11秒：做什么
```

还有：
- ✅ 必做项 Checklist（好的视频都做了什么）
- ❌ 避坑项 Checklist（差的视频都犯了什么错）

### 🧪 AB测试建议
下一轮你可以测试什么变量，怎么测。

### ✅ 发布前检查清单
发视频前对照打勾，确保每条都踩在点上。

## 常见问题

### Q：需要多少条视频才能做对比？
A：建议好的5条 + 差的5条，一共10条左右效果最好。太少了对比不出来规律。

### Q：我没有5秒完播率这些数据怎么办？
A：没关系，有播放量和点赞评论就行。它会自动按数据分组。

### Q：它能跨品类对比吗？
A：最好是同一个品类、同一个账号的视频。跨品类的话差异会太多，不好提炼规律。

### Q：我能直接照着模板拍吗？
A：可以。模板里信息顺序是固定的，画风和场景可以换成你自己的。
