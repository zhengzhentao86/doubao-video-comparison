# 抖音电商多视频对比复盘 Skill（S6）

帮你对比多条好视频和差视频，找出爆款规律，沉淀出可复制的内容模板。

---

## 这个 Skill 能帮你做什么？

你给它一堆视频（好的几条 + 差的几条），它会：

1. ✅ 自动下载所有视频
2. ✅ 快速拆解每条视频的结构（开头钩子、产品出现时间、数字出现时间等）
3. ✅ 好组 vs 差组逐维对比，找出"好视频普遍有、差视频普遍没有"的规律
4. ✅ 沉淀出可直接套用的内容模板和分镜头脚本
5. ✅ 输出一份图文并茂的 HTML 报告，方便你学习和参考

**适用场景：**
- 你有一堆投放数据好的视频和数据差的视频，想找出为什么好
- 你想沉淀自己品类的爆款内容模板
- 你做了AB测试，想复盘哪个变量有效

---

## 怎么用？

### 第一步：准备一个数据表格

你需要准备一个 Excel 表格，里面包含这些列：

| 视频ID | 标题 | 播放量 | 引流次数 | 视频链接 | 分组 |
|---|---|---|---|---|---|
| 视频1 | xxx | 2.1w | 803 | https://www.douyin.com/video/xxx | 好 |
| 视频2 | xxx | 4577 | 97 | https://www.douyin.com/video/xxx | 差 |
| ... | ... | ... | ... | ... | ... |

**注意：**
- 好组至少 5 条，差组至少 5 条，总共至少 10 条视频。样本太少结论不准。
- 分组可以你自己标（好/差），也可以让它自动按数据排序分组。
- 视频链接是抖音的视频链接就行。

### 第二步：把表格发给我

直接把 Excel 表格发给我，然后说：

> "用这个S6对比复盘skill，分析一下这些视频，找出好视频和差视频的差异，沉淀出内容模板。"

就可以了。剩下的它会自动做。

---

## 它会输出什么？

一份 HTML 报告，里面有：

1. **核心结论**：一句话告诉你，好视频和差视频最大的区别是什么
2. **数据总览表**：所有视频的关键指标对比
3. **逐维对比统计**：每个维度好组 vs 差组的百分比对比（比如"好组67%有强钩子，差组0%"）
4. **同类型对照**：比如同是古装AI，好的那条vs差的那条，左右对比，配帧图
5. **爆款规律**：3-5条可复制的规律，每条配正反例子
6. **可复制内容模板**：X秒做什么 + 必做清单 + 避坑清单
7. **分镜头脚本表格**：逐秒写清楚画面、口播、目的
8. **AI生成提示词**：可以直接复制用来生成视频的提示词

## 几个常见问题

**Q：我没有好差分组，只有一堆视频数据怎么办？**
A：没问题。它会自动按数据排序，前30%算好组，后30%算差组，中间的作为参考。

**Q：需要多少条视频才够？**
A：好组至少5条，差组至少5条，总共至少10条。越多越准。

**Q：处理一条要多久？**
A：10条视频大概15分钟左右。因为要下载、抽帧、拆解、对比，需要一点时间。

**Q：需要我手动下载视频吗？**
A：不需要。它会用浏览器自动化自动下载。第一次用的时候如果浏览器没登录抖音，需要你手动登录一下，后续就不用了。

**Q：输出的报告我怎么看？**
A：输出是一个 HTML 文件，你直接用浏览器打开就能看，图文并茂，很清晰。

## 和 S5（单视频拆解）的区别？

- **S5（单视频拆解学习）**：拆一条视频，告诉你这条好在哪里，你可以学什么。
- **S6（多视频对比复盘）**：拆一堆好视频和差视频，对比找出规律，沉淀出可复制的模板。

简单说：S5是学一条，S6是总结一堆，然后沉淀出方法论。
